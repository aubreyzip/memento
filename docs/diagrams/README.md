# Memento Diagrams

The `.mmd` files are Mermaid source and can be previewed in GitHub, VS Code extensions, or Mermaid-compatible Markdown viewers.

- `system-context.mmd` — app boundaries and OS integrations.
- `application-architecture.mmd` — proposed software layers.
- `use-case-overview.mmd` — primary actor/use-case overview.
- `data-model.mmd` — entity relationships.
- `quick-capture-flow.mmd` — unsorted and assigned entry flow.
- `backup-restore-flow.mmd` — safe export and import workflow.
- `startup-key-recovery.mmd` — startup key-state handling and unreadable-database recovery (O-019, SDD §8.1.1).
